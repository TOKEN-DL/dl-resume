# 05: 题库页 —— 浏览、收藏、删除、按套分组

**What to build:** 一个「我的题库」页面：能看到我押过的所有题目，按批次分组，每组显示来源简历、生成时间、题数和用的哪个引擎。每道题能展开看答案、能收藏/取消收藏、能删；整组也能删。

这一片的题目先由一个种子脚本灌进去，用于演示和后续端到端测试。

**Blocked by:** 03、04

**Status:** ready-for-agent

- [ ] 页面按批次分组展示，组头显示来源简历、生成时间、题数
- [ ] 每题能展开答案、收藏/取消收藏，切换后立刻生效并持久化
- [ ] 能删单题、删整套；删完整套后该组消失
- [ ] 只看得到自己的题目
- [ ] 顶部有「再押一套」入口指向押题页
- [ ] 种子脚本能灌入一组示例题
- [ ] 无题时给出空状态提示，不是白屏
- [ ] 越权访问他人的题目返回拒绝，不是数据泄漏
