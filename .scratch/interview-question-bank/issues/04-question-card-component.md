# 04: 题卡组件 —— 题干常显、答案折叠

**What to build:** 一张题目的卡片，作为押题页和题库页共用的展示单元。**题干永远可见，参考答案默认收起** —— 用户先自己答，答不出来再点开看。

卡片上还带三个标签（难度 / 基础还是深挖 / 考点关键词）和一个星级按钮。

星级在两个页面语义不同，由调用方通过属性决定：

- 押题页 = 「重点关注」。入库前题目还不在库里，收藏没有落点；勾选的题在确认入库时直接落成收藏
- 题库页 = 「收藏 / 取消收藏」，当场生效并持久化

折叠用受控组件（按钮 + `aria-expanded`），不用原生 `<details>`：样式可控，且与仓库现有组件风格一致。折叠态**不显示答案摘要** —— 答案只整段出现，避免用户一眼瞥到要点。

**Blocked by:** 03（题目类型定义随数据层一起产出）

**Status:** ready-for-agent

- [ ] 题干始终可见；参考答案内容初始不在渲染结果里
- [ ] 点「看参考答案」后答案出现，再点收起；按钮带 `aria-expanded`
- [ ] 难度 / 分类 / 考点三个标签正确渲染
- [ ] 星级按钮可点，回调能拿到新的收藏状态
- [ ] 同一个组件能同时服务「本地 state 驱动」与「接口回写驱动」两种用法
- [ ] 组件测试（jsdom）覆盖初始折叠、展开收起、星级切换
