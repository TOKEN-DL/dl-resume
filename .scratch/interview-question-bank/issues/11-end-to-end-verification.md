# 11: 端到端验证 —— 走通面试押题全链路

**What to build:** 用真实浏览器走一遍完整流程，确认这件事真的能用，而不只是每个零件单独测都能过。

要走的这一条路：

选一份简历 → 发起押题 → 看着进度条推进 → 看到 12 道题 → 展开一道题的参考答案 → 标记一道题为重点关注 → 确认入库 → 跳到题库 → 看到这一套 → 收藏其中一道 → 筛选出收藏的题 → **对同一份简历再押一次** → 确认题库里没有产生重复题。

最后一步是整个特性的意义所在，必须真的跑，不能只靠单元测试推断。

**Status:** ready-for-agent

- [ ] 折叠答案在页面刷新后仍默认收起
- [ ] 收藏状态刷新后仍在
