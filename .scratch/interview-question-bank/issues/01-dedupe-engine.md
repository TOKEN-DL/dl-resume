# 01: 判重引擎 —— 归一化指纹与三层重复判定

**What to build:** 一套能判定「两道面试题是不是同一道」的纯逻辑。给定一道新题和已有题库，回答两个问题：这道题是否与已有题重复？这一整套题是否与某一套已有题高度重复？

重复判定分三层，命中任一即判为重复：

- **R1 精确** —— 归一化后完全相同
- **R2 近似** —— 字符 bigram 的 Jaccard 相似度 ≥ `0.82`
- **R3 同考点** —— 考点（topic）归一化后相同

R3 是最关键的一层。模型每次出的「同考点不同问法」，文本相似度往往只有 0.3~0.5，靠 R2 抓不住；但让模型在生成时自己标注考点（如「RAG 召回策略」），等于让它先把问题归一化了一次，判定退化成确定性的字符串相等。

归一化算法（来自设计文档 §4.3，编码了去重决策本身）：

```
全角 → 半角
转小写
去掉所有空白
去掉所有中英文标点
剥离开头填充词，最多剥 2 轮：
  请介绍一下 / 介绍一下 / 请谈谈 / 谈谈 / 说说 / 请说说 /
  简述 / 描述一下 / 请描述 / 说一下 / 聊聊 / 请聊一下
```

- 指纹 = `sha1(归一化文本)` 取前 16 位
- 相似度 = 两个归一化文本的字符 bigram 集合的 Jaccard
- 套级：重复率 ≥ `55%`（即 `ceil(题数 × 0.55)`，12 题时 7 题）判定为「整套高度重复」

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 归一化覆盖全角/半角、大小写、空白、中英文标点、填充词剥离，每项各有用例
- [ ] 同一文本两次归一化结果一致；不同文本不产生相同指纹
- [ ] R1 / R2 / R3 各有用例：完全相同、换标点近似、同考点换皮、确实不同
- [ ] 套级判定按比例：12 题时 7 题触发 / 6 题不触发；6 题时 4 题触发 / 3 题不触发
- [ ] 判定逻辑是纯函数，不依赖数据库、网络或模型调用
- [ ] 相似度阈值与套级比例是具名常量，不是散落的魔法数字
