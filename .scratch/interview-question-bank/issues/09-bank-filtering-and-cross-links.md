# 09: 题库筛选与两页互跳

**What to build:** 题库页加筛选条，让我能从几百道题里快速捞出想复习的那几道：按来源简历、按基础还是深挖、按难度档、只看收藏，外加一个关键词搜索（同时匹配题干、答案与考点）。

同时把两个页面打通：押题页有「去题库」，题库页有「再押一套」。

**Blocked by:** 05、07

**Status:** ready-for-agent

- [ ] 筛选条支持：来源简历 / 分类 / 难度 / 仅看收藏
- [ ] 关键词搜索同时匹配题干、参考答案与考点
- [ ] 筛选条件可叠加，且能在 URL 上体现（刷新后条件还在）
- [ ] 筛选无结果时给出明确提示，不显示空白页
- [ ] 押题页有「去题库」入口，跳到题库页
- [ ] 题库页有「再押一套」入口，跳回押题页
- [ ] 筛选在题库变多后仍能快速响应（走数据库查询，不是全量拉回来在内存里过滤）
