**优先级**:P1 · **里程碑**:M4 · **预计**:0.5 天

## 验收

- 简历优化与面试押题共用同一份模型调用代码,不再各写一份
- 简历优化的提示词与业务行为一字未改
- 原有 387 条单元测试一条不少地继续通过

## 子任务

- [ ] TDD:原有测试随实现一起迁移,import 路径调整后仍全绿
- [ ] 抽出「发请求 / 剥思考块 / 抠 JSON / 读思考开关」四件事
- [ ] 优化模块改为引用共享实现,本地不残留重复的 JSON 解析
- [ ] 思考开关仍默认关闭,可用环境变量切回

## 设计要点

这是前置整理:先把改动变容易,再做容易的改动。
本片**不产出任何用户可见变化**,验收标准就是「行为完全等价 + 测试数量不减」。
