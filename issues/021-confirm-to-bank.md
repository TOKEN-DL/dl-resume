# #21 押题确认入库(写库 → 题库出现)

**优先级**:P0 · **里程碑**:M4 · **预计**:0.5 天

## 验收

- 确认后题目写进题库,题库里能看到这一套
- 二次确认层如实显示入库题数与跳过的重复题数
- 押题页勾了「重点关注」的题,入库后已是收藏状态

## 子任务

- [ ] TDD:确认入库接口测试(写入成功 / 重复跳过 / 越权拒绝)
- [ ] POST /api/interview/[jobId]/confirm:写入批次与题目
- [ ] 二次确认层显示「N 题入库 / 跳过 M 题重复」
- [ ] 成功后提示「已入库 N 题 → 去题库」并能跳转
- [ ] 取消确认不写库,任务仍可再次确认
- [ ] 重复点确认不会产生第二份
- [ ] 押题页的「重点关注」随入库落成 starred
