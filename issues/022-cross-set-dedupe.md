# #22 跨套判重接入(重复押题不再产生重复题)

**优先级**:P0 · **里程碑**:M4 · **预计**:0.5 天

## 验收

- 对同一份简历再次押题,题库里不出现重复的题
- 整套重复率超阈值时提示并可由用户拍板是否仍然入库

## 子任务

- [ ] TDD:跨套判重与套级拦截的集成测试
- [ ] 生成前规避:出题提示词带上该简历已出过的题干清单(最近 60 条)
- [ ] 生成后判定:入库前用 #15 的引擎逐题判重(R1/R2/R3)
- [ ] 套级拦截:重复率 ≥ 55% 时整套不入库,页面出提示条
- [ ] 「仍要入库(只保留不重复的 N 题)」按钮,跳过重复题后写入
- [ ] 判重结果在确认层里如实显示
- [ ] 题库里同一道题始终只有一份

## 设计要点

**这是整个需求的核心验收点**,必须真的跑通,不能只靠单元测试推断。

两层防线:
- **生成前规避** —— 把已出过的题干喂给模型让它避开。这是主力
- **生成后判定** —— 入库前逐题判重

不硬拦死:R3 可能误杀「同考点但确实不同」的题,所以留了「仍要入库」这个逃生口。
