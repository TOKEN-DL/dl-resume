# #25 面试押题端到端验证

**优先级**:P0 · **里程碑**:M4 · **预计**:0.5 天

## 验收

- 浏览器走通完整流程:选简历 → 出题 → 展开答案 → 标记重点 → 入库 → 题库可见 → 收藏 → 再次押题不产生重复
- 用例可重复执行,不依赖上次残留数据

## 子任务

- [ ] Playwright:选简历 → 发起押题 → 进度条推进 → 看到 12 道题
- [ ] 展开一道题的参考答案;折叠答案刷新后仍默认收起
- [ ] 标记「重点关注」→ 入库 → 题库可见 → 已是收藏状态
- [ ] 收藏切换刷新后仍在
- [ ] 对同一份简历再押一次 → 题库里同一道题仍只有一份(题数不因重复押题虚增)
- [ ] 整套高度重复时提示条与「仍要入库」按钮出现且行为正确
- [ ] 未登录访问押题页与题库页被引导去登录

## 设计要点

最后一步是整个特性的意义所在,必须真的跑,不能只靠单元测试推断。
