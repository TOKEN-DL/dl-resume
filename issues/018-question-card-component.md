# #18 题卡组件(题干常显、答案折叠)

**优先级**:P0 · **里程碑**:M4 · **预计**:0.5 天

## 验收

- 题干永远可见,参考答案默认收起,点开才出现
- 卡片带难度 / 分类 / 考点三个标签
- 星级可点,押题页与题库页语义不同

## 子任务

- [ ] TDD:组件测试(jsdom)覆盖初始折叠、展开收起、星级切换
- [ ] 题干常显 + 答案默认收起,折叠用受控组件(button + aria-expanded)
- [ ] 难度 / 分类 / 考点三个标签渲染
- [ ] 星级在押题页 = 「重点关注」(入库时落成收藏),在题库页 = 「收藏 / 取消收藏」
- [ ] 同一组件支持「本地 state 驱动」与「接口回写驱动」两种用法
- [ ] CSS Modules,纯选择器必须含本地类名;复用既有设计令牌

## 设计要点

不用原生 `<details>`:样式可控,且与仓库现有组件风格一致。
折叠态**不显示答案摘要** —— 答案只整段出现,避免用户一眼瞥到要点。
