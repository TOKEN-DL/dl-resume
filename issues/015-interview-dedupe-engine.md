# #15 面试押题判重引擎(归一化指纹 + 三层判定)

**优先级**:P0 · **里程碑**:M4 · **预计**:0.5 天

## 验收

- 一道题是否与已有题重复能被判定(精确 / 近似 / 同考点三层)
- 一整套题是否与某一套高度重复能被判定(按比例,不是写死题数)
- 判定是纯逻辑,不依赖数据库、网络或模型调用

## 子任务

- [ ] TDD:归一化(全角/半角、大小写、空白、中英文标点、开头填充词剥离)
- [ ] TDD:指纹稳定(同文本同指纹,不同文本不碰撞)
- [ ] TDD:R1 精确 / R2 近似 / R3 同考点 三条判定各有用例
- [ ] TDD:套级按比例判定(12 题时 7 题触发、6 题不触发;6 题时 4 题触发、3 题不触发)
- [ ] 相似度阈值与套级比例提为具名常量,不留魔法数字

## 设计要点

### 判定三层

| 规则 | 判据 | 抓什么 |
|---|---|---|
| R1 精确 | 归一化后完全相同 | 一字不差的重复 |
| R2 近似 | 字符 bigram 的 Jaccard ≥ `0.82` | 换标点换措辞的微调 |
| R3 同考点 | 考点归一化后相同 | **换皮问法**(模型最常见的重复形态) |

R3 是关键一层:模型每次出的「同考点不同问法」文本相似度往往只有 0.3~0.5,靠 R2 抓不住;
让模型在生成时自己标注考点,等于让它先把问题归一化了一次,判定退化成确定性的字符串相等。

### 归一化算法

```
全角 → 半角
转小写
去掉所有空白
去掉所有中英文标点
剥离开头填充词,最多剥 2 轮:
  请介绍一下 / 介绍一下 / 请谈谈 / 谈谈 / 说说 / 请说说 /
  简述 / 描述一下 / 请描述 / 说一下 / 聊聊 / 请聊一下
```

指纹 = `sha1(归一化文本)` 取前 16 位。
相似度 = 两个归一化文本的字符 bigram 集合的 Jaccard。
套级:重复率 ≥ `55%`(即 `ceil(题数 × 0.55)`)判定为「整套高度重复」。
