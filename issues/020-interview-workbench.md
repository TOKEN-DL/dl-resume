# #20 面试押题工作台(选简历 → 出题 → 进度 → 题卡)

**优先级**:P0 · **里程碑**:M4 · **预计**:1 天

## 验收

- 选一份简历发起押题,提交后立刻进入进度界面
- 跑完看到 12 道题,按难度从易到难排,题干可见、答案折叠
- 后台跑,切到别的页面继续跑,回来进度不丢
- 顶栏出现「◎ 面试押题」入口

## 子任务

- [ ] TDD:本地兜底出题器(按技能与项目套模板)与题目分布校验
- [ ] 模型出题:12 题 = 4 档难度 × 3 题,基础知识 6 + 项目深挖 6,每题带考点
- [ ] 后台任务:globalThis 任务表 + 节点推进 + 轮询接口(照搬优化模块的机制)
- [ ] 进度条五个节点:简历扫描 → 出题 → 查重 → 出答案 → 待确认入库
- [ ] 本片的「查重」只做套内判重;跨套判重与套级拦截在 #22 落地
- [ ] UI:来源选择 + 进度面板 + 题卡列表
- [ ] 无模型密钥时仍能出题(本地兜底)并明确标注兜底模式
- [ ] 顶栏加「◎ 面试押题」,当前页有激活态
- [ ] 题干与参考答案里不出现表情符号
